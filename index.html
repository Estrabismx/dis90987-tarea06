Acerca de la Web

Esta aplicación web es un Traductor de bits que procesa cualquier fotografía cargada barriendo sus columnas de izquierda a derecha. Cada bloque analiza su color: la posición define la nota base, el matiz (rojo, verde, azul, violeta...) la sube hasta una octava y la intensidad del color define el volumen, generando frecuencias musicales en tiempo real.
