Acerca de la Web

Esta aplicación web es un Escáner Sónico de Imágenes que procesa cualquier fotografía cargada barriendo sus columnas de izquierda a derecha. Cada columna calcula el promedio de sus colores RGB e interpreta el brillo para generar frecuencias musicales en tiempo real mediante un sintetizador web avanzado.
