# Traductor de Bits (Escáner Sónico de Imágenes)

**1. Concepto y relación imagen–sonido**  

Nuestro proyecto consiste en el diseño de una página web que permite al usuario subir una fotografía para traducirla en audio en tiempo real. La plataforma escanea los píxeles de la imagen cargada y, según su brillo, color y distribución, genera sonidos utilizando distintos tipos de ondas o "sabores" de audio. El objetivo principal es que el espectador pueda escuchar la luz y las sombras de la foto elegida, las zonas más oscuras generan frecuencias graves, mientras que las áreas más iluminadas se traducen en notas agudas, permitiendo percibir la textura visual a través del sentido auditivo.
